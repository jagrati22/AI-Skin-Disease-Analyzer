# AI Skin Disease Analyzer 🩺✨

This is a **Deep Learning** based web application that helps in the early detection of various skin conditions like **Acne, Eczema, and Psoriasis** using Convolutional Neural Networks (CNN).

## 🚀 Key Features
- **Real-time Analysis:** Get results within 2-3 seconds.
- **High Accuracy:** Achieved an efficiency of **~70-75%** on the Kaggle dataset.
- **User-Friendly UI:** Built with Flask, HTML, and CSS for a smooth experience.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Deep Learning:** TensorFlow, Keras
- **Computer Vision:** OpenCV
- **Frontend:** HTML5, CSS3, JavaScript

## 📊 Project Outcomes (Chapter 6 Highlights)
- Successfully implemented a CNN architecture for multi-class skin disease classification.
- Reduced the need for initial physical consultation for minor skin issues.
- Integrated automated image preprocessing to handle various lighting conditions.

## 🔧 How to Run
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
